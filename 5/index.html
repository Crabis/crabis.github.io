Part 0.4: Undistorting images and creating dataset

For this part, I split my sets accordingly, every 8th image was used for validation, and the rest for training. For the test set, I created a circular path around the object at a fixed height using spherical coordinates to generate camera poses. The radius was set to be slightly larger than the average distance of the training cameras from the object to ensure a good view of the object. Additionally, I saved the camera matrix as K so that I could easily access it and use it later on when training and rendering.

Part 1: Fit a Neural Field to a 2D Image

For this part, my model architecture is as follows:

- Input (u,v) -> PE -> 42D vector
- 42D -> Linear(256) -> ReLU
- 256D -> Linear(256) -> ReLU
- 256D -> Linear(256) -> ReLU
- 256D -> Linear(3) -> Sigmoid -> Output (r,g,b)

(This is the same as the suggested architecture in the assignment)

In total, there are 4 layers and the learning rate used is 1e-4. I used L=10 for positional encoding. I also used a bach size of 10240
Comparing width and L values, I found that having a larger L allowed for more high frequency details and having a higher width allowed for better fitting of the image.

Part 2.1: Create Rays from Cameras

For the Camera to World Coordinate function, I used torch to implement the function for batching. The matrix is converted to homogenous coordinates then multiplied by the camera to world matrix to get the world coordinates.

For the pixel to coordinate function, I used the camera intrinsics matrix to convert the pixel coordinates.

Finally for the pixel to ray function, I took ro as the camera origin in world coordinates (using the translation vector from the camera to world matrix). For rd, I computed the direction by subtracting the pixel coordinates in world coordinates by the camera origin, then normalizing it.

Part 2.2: Sampling

For the sampling rays from images function, I used the approach of flattening the pixels and then sampling N random samples.

For the sampling along rays function, I added a parameter to allow for random sampling within each bin.

Part 2.4: Neural Radiance Field

For my model architecture, I used the same as the one suggested in the assignment:
- Input 3D points (x) and 3D view directions (d).
- PE(x) with L=10 frequencies -> 63D vector.
- PE(d) with L=4 frequencies -> 27D vector.
- First Linear layer takes PE(x) as input, (63 -> 256).
- 8 Linear(256) layers for processing 3D points (x), except for the 5th layer:
    - After the 4th layer, PE(x) is concatenated as a skip connection (256 + 63 -> 256).
- A final Linear(1) + ReLU to get sigma.
- A final 2-layer MLP for RGB:
    - Takes the 8th layer's output
    - Concatenate it with PE(d), so it is (256 + 27 -> 128)
    - Pass through 2 final layers (128 -> 3) + Sigmoid to get RGB.

Part 2.5: Volume Rendering

For this part, I used the torch cumprod function to efficiently compute the transmittance T. Then using T, I computed the weights and finally the RGB. I used the assertion statement given to verify my implementation.

The results of all my functions on the lego dataset is shown below. For the lego datset, I used near = 2.0 and far = 6.0. I ran 3000 iterations at batch size of 4096 (due to GPU memory constraints). I achieved a PSNR above 23.
